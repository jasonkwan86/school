# Intro

Optional Shaders assignment made with Unity 2022.3.62f1 with URP.

# How to play

No way to play. Just open up assignment scenes under `Assets/Shaders/AssignmentShaders` in the editor and observe shader effects.

# Notes

- Fullscreen shader template was taken from URP's built-in StopNaNs shader
- Learning materials I used to learn HLSL shaders in Unity are under `Assets/Shaders/TestShaders`
- Toon shader has 2 options
    - Uncheck `Use Optional Texture` checkbox to use base color or
    - Check `Use Optional Texture` checkbox to use the texture's color
