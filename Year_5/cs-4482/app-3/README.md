# Description

App 3 made with Unity 2022.3.62f1 built upon App 2 with the following additions:

- Left shift for dodge rolls
- Health pickups
- Final big boss with new bullet patterns
- Player must collect keys to unlock doors to proceed
- Exploding shardmites follow the player
- Added 3 max health points for player + invulnerability time after being hit
- General polish (Sound effects + animations added to actions)

# Controls

- wasd to move the player around
- left shift for dodge rolls
- m1 for short range attacks
- m2 for long range projectile attacks (attacks will move toward the mouse cursor)
- esc for opening pause menu

# Goal

The goal of the game is collect all keys to unlock doors, navigate the player to the boss, defeat it, and reach the goal area
