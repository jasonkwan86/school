App 1 made with Unity 2022.3.62f1 usingUnity's [2D beginner adventure game tutorial](https://learn.unity.com/course/2d-beginner-adventure-game?version=2022.3)

Controls:
Arrow keys to move player around.
x for talking to npcs
c for launching a projectile to fix npcs in the player's facing direction
v for melee attack to fix npcs in the player's facing direction

Modification:
The player can press v to do a melee attack that has the same fixing effect on enemies. Implemented with a raycast and accompanied with a wrench animation and controller.
