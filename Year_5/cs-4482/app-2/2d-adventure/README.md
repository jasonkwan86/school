# Description

App 2 made with Unity 2022.3.62f1 according to `A 2D Adventure`

# Controls

- wasd to move the player around around
- m1 for short range attacks
- m2 for long range projectile attacks (attacks will move toward the mouse cursor)
- esc for opening pause menu

# Goal

The goal of the game is to navigate the player to the finish area marked by a green rectangular box

# Notes

Some sprite assets are taken from [Hollow Knight](https://store.steampowered.com/app/367520/Hollow_Knight/)
